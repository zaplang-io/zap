- **Calling a function value read back from a typed collection now works**
  (I#1348, decisions/lang/1348-fn-value-collection-element-kind.md). A
  first-class function value (`fn(..) -> R`) stored in a `list`/`dict`/`set`/
  `channel` — or a collection-typed struct field — and read back by iteration
  (`for cb in callbacks:`), by indexing (`callbacks[0]()`), or through an
  unannotated `auto cb = callbacks[0]` failed IR lowering with `error[ZAP6001]:
  call to unknown function 'cb'` even though the program type-checked. The
  collection element kind collapsed every reference element to a bare pointer,
  so the value lost its `fn(..) -> R` type on read-back and the call fell through
  to a top-level name lookup instead of an indirect closure call. A dedicated
  `fn`-value element kind now preserves the signature, so the read-back value
  stays callable and the call lowers to an indirect `CallClosure`. This covers a
  callable with parameters and one returning a non-scalar — including the
  observable-gauge shape (a list of callbacks each returning a list of
  observations). A function value held directly in a variable (first-class
  functions, I#163) was already callable and is unchanged.
