- **Global regex match `=~ m/.../g` is now iterable** (I#1078,
  decisions/lang/1078-global-regex-match-iter.md, governing design D-0010). The
  global match form now yields a `list[Match]` of all ordered, non-overlapping
  matches (Python `re.finditer` semantics) instead of type-erroring `ZAP4070:
  type 'Match' is not iterable`. Iterate it directly — `for mt in text =~
  m/\w+/g: print(mt.group(0))` — with full numbered and named capture access on
  each match. Zero-length matches make forward progress by a whole UTF-8 code
  point, so patterns like `m/a*/g` terminate and count correctly on ASCII and
  multibyte input; no match yields an empty iteration. The single-match form
  `=~ m/.../` (a bare `Match`) and `s///g` substitution are unchanged.
