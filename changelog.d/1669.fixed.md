- **A generic call now infers its type parameter from a bare callable reference**
  (I#1669, decisions/lang/1669-infer-generic-arg-from-callable.md). Passing a
  top-level function by name to a generic function whose parameter is a bare type
  variable — `accept(callback)` where `def accept[Inner](Inner previous)` — used to
  fail with `ZAP6001: cannot infer type argument 'Inner' ...; write it explicitly
  (I#161)`, forcing an explicit typed local
  (`fn(Context, Namespace) handler = callback`). A bare function name now carries
  its full `fn(params) -> ret` signature (the first-class function value of
  D-0067), so the parameter is pinned from the reference directly, including
  through the return-type sink and for the compiler-synthesized decorator adapter
  of the #1647 generic seam (unblocking the imported-decorator path for
  zaplang-io/cli#4). A local binding still shadows a same-named function, a generic
  or un-annotated-parameter function reference stays untyped, and a genuinely
  un-pinnable parameter still reports ZAP6001.
