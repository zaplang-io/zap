- **Compile-time type introspection foundation — `reflect.type_info(T)` (E1)**
  (I#1257, epic #1248, decisions/lang/1257-type-info.md). The read-only
  type-shape model the upcoming `@derive`/serde work (#1248) is built on: a
  `TypeInfo` describing a type's `kind`, `name`, `fields` (name, type, 0-based
  index, attributes, span — declared data fields in declaration order) and enum
  `variants` — nominal for user `struct`/`enum`, structural for `tuple`/`list`/
  `dict`/`Optional`. This phase is compiler-internal and assert-tested host-side;
  there is **no Zap-level syntax yet** (`comptime` / `reflect.type_info` become
  callable with the comptime evaluator, #1250). No behavior change for existing
  programs.
