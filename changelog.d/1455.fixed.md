- **A method returning `Self` is now usable at the call site**
  (I#1455, decisions/lang/1455-method-self-type-resolution.md). A method whose
  declared return type (or a non-`self` parameter) is `Self` was not resolved to
  the enclosing type in codegen, so its result typed as a non-struct and a field
  access on it failed with `error[ZAP6001]: field access on a non-struct value`.
  The codegen signature now substitutes `Self` for the enclosing type (struct,
  tier-1 or tier-3 enum) at the method's return and parameters, matching sema, so
  `p.clone().x` and chained `Self`-returning calls work — hand-written or
  library-derived. This also lets a library codec decoder (`… -> Self`) type as
  the deriving struct, consuming the reflect-construct enabler (#1454).
