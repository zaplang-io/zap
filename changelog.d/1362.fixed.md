- **Reassigning a bare payload into an `Optional[T]` local or global now boxes it
  as `Some(T)`** (I#1362). A plain reassignment `offset = seconds` to an existing
  `Optional[int64]` binding — which sema already accepts, like the bare-payload
  constructor/field/index positions fixed in #1262 — stored the raw scalar (or
  pointer) straight into the Optional slot with no discriminant tag and no
  allocation, because the `name = value` lowering path was the one assignment
  position that never reached the shared `Optional`-wrap chokepoint. A later
  `offset.is_some()` / `offset.unwrap()` then read those raw bits as an `Optional`
  object and crashed with a `SIGSEGV` (e.g. at `0xffffffffffffd5d0`, the bit
  pattern of the payload `-10800`) — a memory-safety violation in a checked
  program. The reassignment now lowers its right-hand side against the binding's
  declared type through the same chokepoint constructor fields, field/index/key
  assignment, `.append`, call arguments and returns use, so a bare payload wraps
  as a tagged/niche `Some(T)` and a bare `None` lowers to the canonical empty
  option. Covers scalar payloads (including `0` and `INT_MIN`), reference and
  collection payloads (`Optional[str]`, `Optional[Item]`, `Optional[list[int64]]`),
  reassignment cycles (`Some` → `None` → `Some`), crossing a call boundary, and a
  module-level mutable global; an already-`Optional` source is never double-wrapped.
