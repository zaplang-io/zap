- **Built-in `@derive(Json)` supports nested-collection codec elements** (I#1533,
  epic #1529, decisions/lang/1533-nested-collection-codec-elements.md). A collection
  field whose element/value is itself a collection — `list[list[T]]`,
  `dict[str, list[T]]`, `list[dict[str, T]]`, nested to any depth, with scalar / str
  / bytes / nested-struct leaves — now round-trips. The list/dict codec recovers the
  nested element's full type from the `Elem::Nested` interner and recurses through
  the same per-element codec. Json only: a yaml nested-collection element stays a
  clean error (its flow encode would need a `to_json` yaml structs lack), and a
  value-position `Optional` (`list[Optional[T]]`) remains a separate follow-up. This
  completes epic #1529 — the built-in codecs now cover scalar / str / bytes /
  nested-struct / `Optional` / `list` / `dict` fields.
