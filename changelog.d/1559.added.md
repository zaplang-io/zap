- **E5: library `@derive(Json)` encode for `list` / `dict` fields** (I#1559,
  epic #1551, decisions/lang/1559-json-encode-collections.md). The library
  `JsonBytes` generator (#1554) now encodes `list[T]` and `dict[str, V]`
  collection fields (the built-in surface from #1530 / #1531), dispatching each
  element/value leaf on its comptime element type (`f.ty.elem` / `f.ty.value`)
  and recursing into a nested derived struct via its own `to_jsonbytes()`. A
  `list[T]` is encoded **byte-identically** to the built-in (ordered); a
  `dict[str, V]` is proven by round-trip keyed inspection for multi-entry dicts
  (iteration order is unspecified, #1066) and byte-identically for the
  order-trivial empty / single-entry cases. No new comptime primitive; the
  built-in codegen and prelude are untouched.
