- **Reflected binary operators — execution lowering (I#1187, epic I#1189, builds on I#1186/#1192).** AST→ZIR lowering now emits the reflected call so reflected operators actually run, completing the end-to-end path: `a OP b` desugars to `b.__rOP__(a)` (right operand as `self`) when the left operand has no forward handler. The left/built-in path still wins — a struct left that defines the forward dunder, and all built-in arithmetic, are unchanged — and the reflected call is `throwing_call` (invoke), so a raising reflected dunder is catchable. A struct left with no forward dunder now falls back to the right operand's reflected dunder (`dt + rd` → `rd.__radd__(dt)`); a built-in left with a struct right does too (`3.0 * v` → `v.__rmul__(3.0)`). When neither side handles the operator the original clean "missing dunder" error is preserved.
