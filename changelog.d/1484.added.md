- **E4 dogfood: the `@derive(Yaml)` codec shadow-proved over the `@derivable`
  mechanism** (I#1484, epic #1429, decisions/lang/1484-yaml-codec-shadow.md),
  completing the E4 codec trio (Json #1470, Csv #1480, Yaml). Two library
  `@derivable` generators express a YAML encode (`to_yamlcodec`) and decode
  (`from_yamlcodec(str) -> Self`) over the source-accessible YAML DOM — YAML 1.2
  is a JSON superset, so the public `yaml` module reuses the shared `JsonValue`
  DOM (`yaml.load` / `yaml.dump`), making this the Json shadow with those two
  swapped — using the E4 enablers `reflect.construct` / `reflect.set_field`
  (#1454) and derived-method `Self`-return typing (#1455). A behavior-identical
  golden proves they agree with the built-in `@derive(Yaml)` by round-trip (key
  order is unspecified, so the proof is order-insensitive, not byte-identical),
  covering int / str / bool / float fields and a nested derived struct. Shadow
  proof only — the built-in Yaml codegen, `DERIVABLE_TRAITS` and the prelude are
  left untouched.
