- **`comptime for` dispatch is total over nameless field types** (I#1586, I#1584,
  decisions/lang/1586-comptime-for-nameless-dispatch.md). `reflect` `TypeInfo.name`
  (`f.ty.name`) now returns the empty string for a nameless type kind (`list` /
  `dict` / `Optional` / tuple) instead of raising at comptime, so a dispatch chain
  like `if f.ty.name == "int64": … elif f.ty.kind.name == "dict": …` folds for
  every field kind. Previously a nameless field made the condition unfoldable, the
  whole comptime `if` fell back to a runtime `if`, and the `comptime for` loop
  variable leaked to lowering as `unknown variable 'f'` (also dropping a `match`
  nested in a taken branch, #1584). A new `f.ty.is_named` accessor distinguishes a
  nameless kind from an empty name.
