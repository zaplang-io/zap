- Generic interfaces (`interface X[T]`) are realized for structural conformance: a concrete type conforms to `X[A]` when it provides the interface's methods with the type parameters substituted (`T := A`). The conformance is enforced on generic-interface **bounds** — `def f[T: Container[int64]](…)` and `struct S[T: Container[int64]]` — at each instantiation (static dispatch); a non-conformer is rejected naming the bound with its type arguments. (I#1205, part of epic I#1204.)
