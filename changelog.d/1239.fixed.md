- **`==` / `!=` on lists now compare structurally** (I#1239,
  decisions/lang/1239-list-structural-equality.md). Two lists compare equal when
  they have the same length and equal elements in the same order — Python's value
  semantics — instead of by pointer identity, so a list returned from a function
  now compares `==` to a separately built list with the same contents. `is` /
  `is not` are unchanged (reference identity). This applies to every element type
  (`int64`, `float64`, `str`, `bool`, user structs via `__eq__`, and nested
  lists, which recurse); the defect was never specific to `list[float64]`.
