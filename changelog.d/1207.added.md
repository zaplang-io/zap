- Interfaces may declare **associated / output types** with `type Out` and name them in method signatures. A conformer binds the associated type structurally (by the return of the producing method), and bounded generic code names it as the dotted type projection `T.Out` — so a capability can name its result without a second type parameter (`def build[T: Producer[f64]](T f, f64 s) -> T.Out`). At monomorphization the projection resolves to the concrete binding. (I#1207, completing epic I#1204.)
