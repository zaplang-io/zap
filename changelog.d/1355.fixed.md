- **`sum`, `sorted`, and `in` now work on a `bytes` value** (I#1355,
  decisions/lang/1355-bytes-value-operations, follow-up to byte iteration
  I#1349). These type-checked but failed code generation. `sum(data)` reduces
  the byte values to an `int64` (optional numeric start); `sorted(data)` returns
  a fresh `list[int64]` of the byte values ascending (`reverse=` / `key=`
  supported); and `x in data` / `x not in data` is a `bool` — an `int` left
  operand tests byte-value membership (unsigned `0..=255`), a `bytes` left
  operand tests subsequence membership (the empty `bytes` is always present) —
  matching Python. (`min`/`max` over a single `bytes` remain a documented
  follow-up.)
