- **Route a built-in-named `@derive` to a prelude-provided `@derivable` generator**
  (I#1596, epic #1551, decisions/lang/1596-prelude-derivable.md). The forwarding-
  stub synthesis (`derive_synth::expand_library_derives`) now scans the prelude's
  `@derivable`/`interface` declarations as well as the user module's, and
  `with_prelude` injects a prelude generator's body + interface when a routed
  `@derive` references it — so a `@derivable` trait living in the prelude can serve
  `@derive(Trait)` in any module without the user declaring it. Inert until the
  prelude registers a derivable (the Json retire #1558 is the first), so every
  current program is byte-for-byte unchanged. This is the pipeline prerequisite
  for retiring the built-in `@derive(Json)` in favor of a library generator.
