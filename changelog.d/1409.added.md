- **`time.ticker(d)` — a stoppable periodic timer** (I#1409,
  decisions/runtime/1409-periodic-ticker.md). `time.ticker(d: Duration)` returns
  a `Ticker` handle that delivers a value on `tk.chan` every `d` — the periodic
  companion to the one-shot `time.after` (I#1395):

  ```python
  import time

  auto tk = time.ticker(time.seconds(60))
  while True:
      select:
          case fired = <-tk.chan:
              flush_metrics()
          case stopping = <-done:
              tk.stop()
              return
  ```

  Each tick carries the monotonic-ns instant; the ticker keeps a fixed schedule
  (no drift) and drops a tick if the consumer is behind (bounded memory). `tk.stop()`
  ends it (idempotent); a never-stopped ticker is terminated at program exit rather
  than joined. The firing loop reuses the fd-less scheduler timer, so it consumes
  no file descriptor and many concurrent tickers cannot exhaust them. Linux (epoll)
  only in this version.
