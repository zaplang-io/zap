- **Escape analysis now stack-promotes pointer-bearing structs and length-bounded
  transient strings** (I#1081, decisions/runtime/1081-stack-promote-transients.md;
  builds on the #850 escape pass). A non-escaping reference struct is placed in a
  stack slot even when it has GC-pointer fields — its interior fields are traced
  and move-rewritten in place via an aggregate-root `(base, desc)` pair (#586)
  rather than a heap allocation — and a non-escaping f-string whose length is
  provably bounded (e.g. a transient `f"k{i}"` dict key) is built in a root-free
  stack buffer with no allocation and no per-iteration GC root. No surface or
  semantic change — the same program allocates less and collects less.
