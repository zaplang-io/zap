- **`open(path[, mode])` built-in** (PR#1388, decisions/lang/1388-open-builtin.md). Prelude sugar over `io.open`: `open(path)` opens for reading (mode defaults to `"r"`), `open(path, mode)` passes the mode through. It returns the same `int64` file descriptor `io.open` returns — usable with `io.read` / `io.write` / `io.close_fd` and the `io.reader` / `io.writer` / `io.lines` wrappers — and raises the same catchable errors (`FileNotFoundError` for a missing path, `ValueError` for a bad mode). Arguments are positional. (`input` shipped earlier in #969.)
