- **`bool` ordering comparisons are now correct** (I#1344,
  decisions/lang/1344-bool-zero-extend.md). A `bool` is an unsigned `0`/`1`, but
  it was widened to `int64` by sign-extension, so `True` became `-1` and every
  `bool` ordering comparison was inverted (`False < True` reported `False`). It
  now zero-extends (`True` → `1`), so `False < True` is `True`, matching Python —
  as a scalar and for `bool` elements in `list` / `deque` ordering. Equality and
  `is` / `is not` were unaffected and are unchanged.
