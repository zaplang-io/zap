- **Bundled pure-Zap stdlib modules; `serde` ships blessed in-language** (I#1570,
  epic #1552, decisions/lang/1570-bundled-stdlib.md). The compiler can now ship a
  **pure-Zap stdlib module** embedded in the toolchain, resolved by `import <name>`
  with no `zap add` — a new module-resolution tier (1b, a D-0081 extension) that
  sits after the Rust seam modules and before `zenv` dependencies, parsing the
  embedded source and merging it like any module (so it carries interfaces,
  generics and `comptime` reflection, which a Rust seam cannot). The first bundled
  module is **`serde`** (`import serde`): the `Serializer` / `Deserializer` backend
  interfaces plus the generic `serialize[T, S]` / `deserialize[T, D]` drivers from
  #1562/#1563, now one blessed, version-coherent, in-language serialization
  foundation for the whole ecosystem — fully monomorphized across the module
  boundary, no per-codec compiler change. Registry in
  `crates/driver/src/bundled_stdlib.rs`; source in `crates/driver/stdlib_zap/serde.zap`.
