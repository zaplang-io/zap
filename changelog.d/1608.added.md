- **`reflect.construct` builds a typed empty container** (I#1608, epic #1248,
  decisions/lang/1608-reflect-construct-enum-container.md). `reflect.construct(T)`
  now accepts a `list` / `dict` / `set` / `Optional` type and, for a collection,
  emits the typed empty constructor `list[E]()` / `dict[K,V]()` / `set[E]()` so an
  `auto` binding pins the element type. With the reflect-in-helpers enabler
  (#1604) this lets a library codec decode nested collections of arbitrary depth
  by building a typed accumulator and recursing into the element type.
