- **`sys.getpass([prompt]) -> str` — terminal-safe hidden line input**
  (I#1684, decisions/stdlib/1684-getpass-hidden-input.md). Reads one line from
  stdin with terminal echo suppressed and writes the prompt to stderr (never
  stdout), returning the line without its terminator — the no-echo twin of
  `input()`, analogous to Python `getpass.getpass`. The prompt defaults to
  `"Password: "` and is positional-or-keyword (`sys.getpass(prompt=...)`). stdin
  must be a terminal: a pipe or redirected file raises a catchable `OSError`
  *before* the prompt is written or any byte is read — there is no silent
  fallback to an echoing read, so a secret is never consumed or disclosed on the
  wrong channel (a deliberate divergence from CPython `getpass`, which echoes on
  a non-tty). End-of-input with no bytes raises `EOFError`, like `input()`. The
  original terminal state is restored on every exit (normal return, EOF, or I/O
  error after echo was disabled), and a terminal that already had echo off stays
  off. No typed byte is echoed or placed in any diagnostic text. POSIX termios
  (`ECHO` off / `ECHONL` on, `TCSAFLUSH`) / Windows `SetConsoleMode`
  (`ENABLE_ECHO_INPUT` cleared). Visible `input()` semantics are unchanged.
  Unblocks the hidden-input portion of zaplang-io/cli#11.
