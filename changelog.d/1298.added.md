- **comptime/reflect surface wired to the E2 engine in mono (S2)** (I#1298, epic
  #1296 / #1248, decisions/lang/1298-comptime-surface-engine-wiring.md).
  Monomorphization now drives the parsed `comptime for` surface (#1297) through
  the existing E2 engine: a `comptime for f in reflect.type_info(T).fields:` (or
  `.variants:`) whose `T` names a concrete `struct`/`enum` is unrolled in place,
  with each `reflect.field(value, comptime f.index)` desugared to a typed field
  access (`value.<name>`) — the #1251 unroller + #1252 field lowering. The
  evaluator gains a `reflect.type_info(T)` builtin (its argument is read as a
  type and resolved via the type registry), and `comptime <expr>` unwraps to its
  (already-folded) inner so the marker never reaches lowering. Compiler-internal
  and host-tested over the monomorphized AST. **Not yet end-to-end:** sema still
  reports the fragment as not-yet-implemented (ZAP0002), so a real program using
  `comptime for` does not compile until sema accepts/types the fragment (the
  remaining S2 step); a generic `reflect.type_info(T)` with `T` a type parameter
  is also deferred. No behavior change for existing programs.
