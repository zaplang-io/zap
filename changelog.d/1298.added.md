- **comptime/reflect surface wired to the E2 engine — end-to-end (S2)** (I#1298,
  epic #1296 / #1248, decisions/lang/1298-comptime-surface-engine-wiring.md +
  decisions/lang/1298-comptime-surface-sema-acceptance.md). The parsed
  `comptime for` surface (#1297) now compiles and runs: monomorphization unrolls
  a `comptime for f in reflect.type_info(T).fields:` (or `.variants:`) whose `T`
  names a concrete `struct`/`enum`, desugaring each
  `reflect.field(value, comptime f.index)` to a typed, unboxed field access
  (`value.<name>`) — the #1251 unroller + #1252 field lowering; the evaluator
  gains a `reflect.type_info(T)` builtin (argument read as a type, resolved via
  the type registry), and `comptime <expr>` unwraps to its folded inner.
  **Sema** accepts and types the fragment — `reflect.type_info` / `reflect.field`
  / `reflect.has_override` are comptime builtins (typed `Unknown`, arguments not
  inferred), a `comptime for` binds its loop variable and checks its body, and
  `comptime <expr>` has its inner's type — so a program using `comptime for`
  passes the whole front end and runs (proven by an LLVM golden printing a
  struct's fields). A generic `reflect.type_info(T)` with `T` a type parameter is
  still deferred. No behavior change for programs that use no `comptime`.
