- **char-set `str.strip`/`lstrip`/`rstrip` trims whole codepoints** (I#1636,
  decisions/stdlib/1636-strip-codepoint-charset.md, superseding D-0210's
  byte-based clause). The char set was matched byte-at-a-time, so a multibyte
  character over-stripped and could produce **invalid UTF-8**
  (`"αβγ".strip("α")` yielded a malformed `B2 CE B3`; now `"βγ"`). The set is now
  a set of characters (codepoints), matching CPython, and the result is always
  valid UTF-8. The no-argument whitespace form and ASCII results are unchanged.
