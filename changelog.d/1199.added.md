- **Operator capabilities will be declared prelude generic interfaces (I#1199, epic I#1189, decisions/lang/1199-operator-capability-interfaces.md).** Design locked: the forward (`Add`/`Ord`/…) and reflected (`RAdd`/`RMul`/…, with a left-operand and output type, e.g. `RMul[L, Out]`) operator capabilities become user-nameable generic-interface bounds, so generic code can constrain on them (`def scale_all[T: RMul[f64, T]](...)`). Operator **dispatch** is unchanged (it already ships structurally, #1180/#1198); this only changes how capabilities are named/bounded, and is blocked on the generics epic #1204 (generic-interface conformance #1205 + parametrized bounds #1206; associated types #1207 optional).
