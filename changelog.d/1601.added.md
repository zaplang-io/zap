- **serde breadth: `Optional[T]` fields** (I#1601, epic #1552,
  decisions/lang/1601-serde-optional.md). The bundled `serde` foundation (#1570)
  now (de)serializes `Optional[T]` of a scalar inner. `serde.Serializer` gains
  `emit_nil` and `serde.Deserializer` gains `begin_optional`; the generic
  `serialize` / `deserialize` drivers gain an `optional` branch dispatching on the
  inner type (`f.ty.inner`). Encode emits the inner value for `Some` and a nil for
  `None`; decode distinguishes them via `begin_optional`. (This needed no compiler
  change — the earlier "comptime residual" was a wrong reflection accessor, `.elem`
  instead of `.inner`, on `Optional`.) Downstream codecs (e.g. `zaplang-io/msgpack`)
  need a matching backend update.
