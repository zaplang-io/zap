- **Generic `reflect.type_info(T)` resolves — a generic `comptime for`
  generator unrolls per instantiation (E3b, part 1)** (I#1291, epic #1289 /
  #1248, decisions/lang/1291-comptime-generic-t-resolution.md). Monomorphization
  now resolves the type in `comptime for f in reflect.type_info(T).fields:` /
  `.variants:` through the active type-parameter substitution, so a **generic**
  generator — `def g[T](T p): comptime for f in reflect.type_info(T).fields: …`
  — called at a concrete type unrolls over that type's members per instantiation
  (each `reflect.field(p, comptime f.index)` desugaring to an unboxed field
  access), not only a hand-written concrete type (the S2 behavior). This is the
  mechanism a real `@derive` generator needs; the `@derive` forwarding-stub
  synthesis that targets it is the next E3b slice. Compiler-internal,
  host-tested, and exercised end-to-end by an LLVM golden. No behavior change for
  a non-generic `comptime for` or a program that uses none.
