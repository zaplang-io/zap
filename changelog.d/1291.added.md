- **Generic `reflect.type_info(T)` resolves — a generic `comptime for`
  generator unrolls per instantiation (E3b, part 1)** (I#1291, epic #1289 /
  #1248, decisions/lang/1291-comptime-generic-t-resolution.md). Monomorphization
  now resolves the type in `comptime for f in reflect.type_info(T).fields:` /
  `.variants:` through the active type-parameter substitution, so a **generic**
  generator — `def g[T](T p): comptime for f in reflect.type_info(T).fields: …`
  — called at a concrete type unrolls over that type's members per instantiation
  (each `reflect.field(p, comptime f.index)` desugaring to an unboxed field
  access), not only a hand-written concrete type (the S2 behavior). This is the
  mechanism a real `@derive` generator needs; the `@derive` forwarding-stub
  synthesis that targets it is the next E3b slice. Compiler-internal,
  host-tested, and exercised end-to-end by an LLVM golden. No behavior change for
  a non-generic `comptime for` or a program that uses none.
- **`@derive(Trait)` synthesizes conforming methods for a library-registered
  derivable trait (E3b, forwarding stubs)** (I#1291, epic #1289 / #1248,
  decisions/lang/1291-derive-forwarding-stub-synthesis.md). A type that derives a
  library trait registered with `@derivable(Trait)` (#1290) and declared as a
  structural `interface Trait` now gains, for each interface method, a thin
  method forwarding to the generator specialized at the type —
  `def dump(self): _derive_dump[Point](self)` — so `p.dump()` runs the generator
  over `Point`. The synthesis is a pre-sema desugar, so the method is
  type-checked, conformance-checked and lowered like hand-written code; a
  hand-written method of the same name wins. First cut: a non-generic type and a
  single-method trait of any arity (a generic type stays deferred to E3c;
  multi-method traits forward every method to the one generator). A derive
  generator must not name its generic parameter `self` for now (a pre-existing
  reflect-surface defect, reported separately). No change for a program that
  derives only built-in traits.
