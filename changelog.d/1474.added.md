- **`tuple[T]` equality and hashing (dict/set keys)** (PR#1474, decisions/lang/1474-vartuple-equality.md, decisions/lang/1474-vartuple-hashing.md). Two variadic tuples compare element-wise with `==` / `!=` — equal length and equal elements (CPython tuple semantics), `str`/`bytes` elements by content. A `tuple[T]` is now **hashable** when its element is a scalar / `str` / `bytes` / tier-1 enum, so it can be a `dict` key or `set` member (`d[tuple(path)]`): the hash folds the element hashes so a same-content tuple built separately hits the same entry. Part of the variadic-tuple epic #1461; ordering/concat/slicing are #1475.
