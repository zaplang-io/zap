- **`@derive(X)` on an enum is now recognized and wired (groundwork)**
  (I#1373, epic #1371, decisions/lang/1372-enum-derive-match-surface.md). A
  library `@derive(X)` on an `enum` now synthesizes the same thin forwarding stub
  as on a struct, strips the library trait, and infers serde-style bounds from
  the enum's **variant payload** fields (a type parameter used in any variant's
  payload is bounded). Tier-1 constant enums and tier-3 payload enums both wire
  through, including generic enums (`_derive_dump[Tree[T]](self)`). The runtime
  variant-discrimination surface that lets a real enum codec read the active
  variant's payload — `reflect.match` with comptime-generated arms (decision
  I#1372) — is the next slice (I#1374); until then a generator body that iterates
  variants needs it, but the derive is no longer an unknown/deferred trait on an
  enum.
