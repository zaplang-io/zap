- **`datetime.local_zone() -> TimeZone`** (I#1171,
  decisions/stdlib/1171-system-local-zone.md). Returns the host system's
  configured zone as a reusable **named** `TimeZone` (resolved from `TZ`, the
  `/etc/localtime` symlink, or `/etc/timezone`), so the same handle re-resolves
  correctly across DST in `astimezone` / `resolve` — unlike a one-shot offset
  snapshot. Raises the catchable unknown-zone error when the host zone cannot be
  mapped to a bundled IANA key. Unblocks `dateutil.tz.tzlocal()` / `gettz()` in
  zaplang-io/datetime-utils#3 (#324).
