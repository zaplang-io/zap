- **`argparse` object model — `format_usage()` exposes the usage synopsis on
  its own** (I#1710, decisions/lang/1710-argparse-format-usage.md).
  `ArgumentParser.format_usage() -> str` returns just the `usage:` synopsis
  line, with no trailing newline and none of the description or option rows that
  `format_help()` adds around it. `format_help()` now leads with the same
  builder, so the two can never drift and existing help output is byte-for-byte
  unchanged. The method is pure — it neither parses arguments nor prints nor
  exits — and renders plain options, store_true flags, positionals, hidden
  arguments (#1702), grouped options, custom metavars, custom program names, and
  the subcommand selector exactly as the help usage line does. Mirrors Python
  argparse's `format_usage()`. Unblocks zaplang-io/cli#16.
