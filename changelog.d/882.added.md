- **First-class `MemoryError` exception type** (I#882, decisions/lang/882-memoryerror-exception.md).
  `MemoryError` is now a built-in exception under `Exception` (CPython parity),
  so `raise MemoryError(...)`, `except MemoryError`, and `except Exception` all
  work, and a Python-interop `MemoryError` maps to it. Mirrors how
  `TimeoutError` / `AssertionError` / `EOFError` are wired.
