- **Generic operator dunders now dispatch through operator syntax** (I#1227,
  decisions/lang/1227-generic-operator-dunder-dispatch.md). A dunder with its
  own type parameters — `def __radd__[T](self, T dt) -> T`, or a generic forward
  `def __add__[T]` — now resolves through `a + b` / `a - b` operator syntax,
  instantiated with the concrete operand type, not only through an explicit
  `x.__radd__(y)` call. This lets one package-defined delta handle both core
  `Date` and `DateTime` operands through the reflected-dispatch mechanism
  (#1180). Previously operator syntax reported `ZAP6001 "type 'DateTime' does not
  define '__add__'"`. Non-generic dunders and forward-wins precedence are
  unchanged.
