- **`map()` / `filter()` built-ins** (I#1390,
  decisions/lang/1390-map-filter-builtins.md). `map(func, *lists)` applies `func`
  across one or more lists, stopping at the shortest, into a `list[R]` (R =
  `func`'s return type); `filter(pred, list)` keeps the elements for which `pred`
  is truthy, into a `list[T]` preserving the element type. Both materialize to a
  `list` (matching `reversed`), so they compose with `for`, `list(...)`, and
  `sum(...)` and bind to a `list[...]` directly — e.g.
  `list[int64] ys = map(square, xs)` and `sum(map(square, xs))`. Built on
  first-class function values (#163). Strictly-lazy adapters (no intermediate
  list), non-`list` iterables, and the `filter(None, xs)` keep-truthy convenience
  are documented follow-ups (a clean compile error points there).
