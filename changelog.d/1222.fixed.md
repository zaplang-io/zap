- **Imported generic bounds resolve across module boundaries** (I#1222,
  decisions/lang/1222-imported-generic-bound-name.md). A generic struct, enum,
  function or interface with an interface-bounded type parameter
  (`struct Wrapper[T, C: Codec[T]]`) now compiles when the interface and its
  conformer live in an imported module, not only when everything is in one
  module. The module linker previously mangled the interface declaration and
  the generic's concrete type argument with the module prefix but left the
  interface name *inside the bound* unqualified, so monomorphization failed with
  `'Codec' is not an interface`; the linker now qualifies the bound's interface
  name like every other type reference. Built-in capability bounds
  (`Comparable`, `Hashable`, …) are unaffected.
