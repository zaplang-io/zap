- **Full array index `m[i, j]` / `m[i][j]` no longer allocates per access**
  (I#894, decisions/runtime/894-full-index-flat-offset.md). A full integer index
  into a dense N-D `array[T]` (read, `=`, or `+=`) — written either as the comma
  form `m[i, j]` or as a pure chained form `m[i][j]` — now computes its flat
  element offset inline and issues a single scalar get/set instead of folding
  through an allocated rank-1 row view, removing one GC allocation per element
  access in a hot indexing loop. No surface or semantic change: per-axis bounds
  are preserved (`m[0, 5]` on a `(3, 3)` array still raises) and `m[i, j]` /
  `m[i][j]` keep their results; partial-index views (`m[i]`) and bound row views
  (`row = m[i]`) are unchanged.
