- **Comptime reflection gains a write surface: `reflect.construct(T)` and
  `reflect.set_field`** (I#1454, epic #1429,
  decisions/lang/1454-reflect-construct-field-write.md). A `@derivable` generator
  can now build a value of `T` and populate its fields — the write-counterpart of
  the `reflect.field` read. `reflect.construct(T)` yields a zero-initialized `T`
  (v1: a non-generic struct with scalar / `str` / `bytes` fields) and
  `reflect.set_field(out, comptime i, v)` writes field `i` (desugaring to the
  ordinary assignment `out.<name> = v`). This is the primitive codec decoders will
  build on; it changes no existing program. (Consuming it for a `from_*` decoder
  additionally needs the derived-method `Self`-return fix, #1455.)
