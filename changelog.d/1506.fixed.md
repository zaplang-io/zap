- **`reflect.field` / `reflect.set_field` now desugar inside a `match` case arm**
  (I#1506, decisions/lang/1506-reflect-setfield-match-arm.md). A reflection
  intrinsic used inside a `match` arm of a `@derivable` generator body was left
  un-desugared — the generator-body walk recursed into `if` / `while` / `for`
  blocks but not `match` — so the `reflect` receiver leaked to lowering and the
  program failed with a span-less `error[ZAP6001]: unknown variable 'reflect'`.
  The walk now descends into a `match`'s scrutinee, each arm guard, and each arm
  body, so a codec decoder can populate a field via `reflect.set_field` directly
  from within an arm.
