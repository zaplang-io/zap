- **E5: library `@derive(Json)` struct decode** (I#1557, epic #1551,
  decisions/lang/1557-json-decode-library.md). A library `@derivable` generator
  decodes a struct from JSON over the DOM (`json.loads` + `reflect.construct` +
  `reflect.set_field`), agreeing with the built-in `@derive(Json)` decode:
  `int64`/`str`/`bool`/`float64`, a nested derived struct field, `Optional[int64]`
  (absent/null → `None`, D-0065), `list[scalar]` / `dict[str, scalar]`, and the
  AWS hooks (base64 → `bytes`; number/string → `DateTime` per `@json(timestamp=)`).
  Nested-derived-struct collection ELEMENTS (`list[Item]` / `dict[str, Item]`) are
  blocked on the element-decoder-invocation gap #1575, and enum / generic-struct
  decode on #1561 (both reported under #1248, not worked around). No new comptime
  primitive; the built-in codegen and prelude are untouched.
