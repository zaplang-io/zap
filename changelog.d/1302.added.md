- **`enumerate` and `zip` for-loop built-ins** (I#1302,
  decisions/lang/1302-enumerate-zip.md; epic #1286). `for i, x in enumerate(xs[,
  start])` iterates a list by index, binding the running index and the element;
  `for a, b in zip(p, q, …)` iterates up to the shortest input, binding one
  element from each list per iteration (Python's default `zip`). Both are
  special-cased in the for-loop lowering, so no intermediate list of tuples is
  built. A standalone `enumerate`/`zip` value (outside a for-loop) is a compile
  error pointing at the loop form — a lazy iterator value is a follow-up; non-list
  iterables are a follow-up too.
