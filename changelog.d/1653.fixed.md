- **Struct instance-method calls now type-check their arguments** (I#1653,
  decisions/lang/1653-struct-method-argcheck.md). The struct instance-method path
  previously ran only the generic type-parameter consistency pass (#1622) and
  inferred arguments loosely, so a plain (non-generic) mismatch was silently
  accepted — `struct S: def plain(self, int64 n)` accepted `s.plain("not an
  int")`, while the equivalent enum method call already rejected it (#1642). Each
  positional argument is now checked `coercible` against its declared parameter
  (with `self` dropped so positions line up) and each keyword against its named
  parameter, both `error[ZAP4021]`/`ZAP4022`, closing the struct/enum asymmetry.
  Arity stays loose and the method's return type is unchanged, so the method-chain
  operator typing that drives `&`/`|`/`~` dispatch off the returned struct is
  preserved; consistent calls and numeric widening still compile.
