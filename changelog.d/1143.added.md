- **`net` — AF_UNIX peer credentials** (I#1143,
  decisions/stdlib/1143-peer-credentials.md, follow-up to #993).
  `net.peer_cred(sock) -> (uid, gid, pid)` reads the connecting peer's user id,
  group id and process id off a connected Unix-domain socket — the authorization
  primitive a local daemon uses to check who connected. Works on both a
  `connect_unix` client and an `accept`ed server connection (the AF_UNIX check is
  via `getsockname`); a non-Unix socket raises `ValueError`. **Linux only** for
  now (via `SO_PEERCRED`); macOS/BSD (`getpeereid`/`LOCAL_PEERPID`) and Windows
  raise a catchable "not supported" error, with the macOS/BSD path a follow-up.
  `net` remains Experimental.
