- **`net` keepalive timing now works on Windows** (I#1157,
  decisions/stdlib/1157-windows-keepalive.md, completing #1141).
  `net.set_keepalive_idle(sock, seconds)` and `net.set_keepalive_interval(sock,
  seconds)` route to the `SIO_KEEPALIVE_VALS` ioctl on Windows (matching
  CPython's `socket.ioctl`), keeping the same named setters as POSIX. Because the
  ioctl sets idle + interval together (and enables keepalive), setting one keeps
  the other's last value (Windows default if unset). `net.set_keepalive_count`
  and the `get_keepalive_*` readers raise a catchable "not supported" error on
  Windows (no probe-count knob, no symmetric read). POSIX is unchanged. `net`
  remains Experimental.
