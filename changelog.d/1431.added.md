- **E4 dogfood: `@derive(Eq)` shadow-proved over the `@derivable` mechanism**
  (I#1431, epic #1429, decisions/lang/1431-derive-eq-shadow-prove.md). A library
  `@derivable` generator now demonstrably expresses the compiler's structural
  equality: a struct derives both the built-in `Eq` (used through `==`) and a
  library equality trait, and a behavior-identical golden shows the two agree for
  int / str / bool / float fields and a nested derived struct. This is a shadow
  proof — the built-in `Eq` and the implicit value-struct auto-derive are left
  untouched — so it adds a readable reference generator and a regression guard
  without changing how equality is wired.
