- **Built-in `@derive(Json)` supports `dict[str, V]` fields** (I#1531, epic #1529,
  decisions/lang/1531-json-dict-field.md). A str-keyed dict field now encodes as a
  JSON object and decodes a JSON object back into a dict, for value types `int` /
  `float` / `str` / `bytes` / nested `@derive(Json)` struct. Encode string-builds
  the object recursing into the per-value encoder; decode reads the DOM object via
  a new `__json_as_object` prelude accessor and decodes each value by the object's
  own keys. A JSON object has string keys, so a non-str dict key is a clean error;
  unsupported value kinds (bool/char/enum, nested-collection values like
  `dict[str, list[...]]`) and `set` fields remain a clean "unsupported yet" error
  (follow-ups: Yaml parity #1532, nested-collection elements #1533).
