- **E6.2: a real binary format backend on the serde core** (I#1563, epic #1552,
  decisions/lang/1563-serde-binary-backend.md). A compact self-describing TLV
  binary codec (`BinWriter` / `BinReader`) implemented purely as a `Serializer` /
  `Deserializer` backend (#1562) and driven by the shared generic `serialize` /
  `deserialize` free functions — proving a real, byte-checkable codec is a pure
  library with no compiler change (the #1248 thesis). The golden
  `serde_binary_backend` asserts byte-exact encode (flat and nested frames) plus
  round-trip of edge scalars (negative two's-complement int, empty string, `False`)
  and a multi-byte UTF-8 string; a host test pins per-(type, backend)
  monomorphization and direct backend calls. No new core primitive.
