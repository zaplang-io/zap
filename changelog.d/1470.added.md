- **E4 dogfood: the `@derive(Json)` codec shadow-proved over the `@derivable`
  mechanism** (I#1470, epic #1429, decisions/lang/1470-json-codec-shadow.md). Two
  library `@derivable` generators express a JSON encode (`to_jsoncodec`) and
  decode (`from_jsoncodec(str) -> Self`) over the source-accessible JSON DOM
  (`JsonValue` + public `json.dumps` / `json.loads`), using the E4 enablers
  `reflect.construct` / `reflect.set_field` (#1454) and derived-method `Self`-return
  typing (#1455). A behavior-identical golden proves they agree with the built-in
  `@derive(Json)` by round-trip (key order is unspecified, so the proof is
  order-insensitive, not byte-identical), covering int / str / bool / float fields
  and a nested derived struct. Shadow proof only — the built-in Json codegen,
  `DERIVABLE_TRAITS` and the prelude are left untouched.
