- **`io.isatty(fd) -> bool` — terminal detection for a file descriptor**
  (I#1685, decisions/stdlib/1685-isatty-terminal-detection.md). Reports whether
  a descriptor is connected to a PTY or platform console
  (`io.isatty(sys.stdout_fd())`). A pure, infallible query: a pipe, a redirected
  regular file, a closed descriptor, and an invalid / out-of-range descriptor
  all read as `false` (folding `EBADF` to `false`, CPython `os.isatty` parity)
  — it never raises and leaves the descriptor and terminal state unchanged. Two
  descriptors answer independently, so a program can tell a redirected stream
  from a console when only one of stdout/stderr is redirected. Positional-or-
  keyword (`io.isatty(fd=...)`); POSIX `isatty` / Windows `_isatty`. Unblocks the
  CLI progress bar (zaplang-io/cli#12) and rich help (zaplang-io/cli#16).
