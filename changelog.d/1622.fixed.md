- **A generic method now enforces type-parameter consistency across its arguments**
  (I#1622, decisions/lang/1622-generic-method-consistency.md). Binding a type
  parameter `T` from one argument of a generic method constrains the others, as
  #1545 already does for free functions: `struct Util: def take[T](self, T x, T
  y)` now rejects `u.take(1, "hello")` with `error[ZAP4021]` instead of
  monomorphizing `take$int64` with a string in an `i64` slot (instance-method
  arguments were previously inferred without any type check). Struct instance
  methods and associated calls are covered; the method's return type stays loose
  (generic return binding is I#1623) and enum instance methods are a follow-up.
