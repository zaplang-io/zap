- **`< <= > >=` on lists now compare lexicographically** (I#1334,
  decisions/lang/1334-list-ordering.md), matching Python's sequence ordering:
  element by element, with the first differing element deciding and a shorter
  prefix sorting first. Element ordering reuses scalar `<`/`>` (numeric, `str`/
  `bytes` by contents). Previously list ordering fell
  through to a pointer-address compare, yielding a meaningless result. `is` /
  `is not` are unchanged (reference identity); list `==` / `!=` were already
  structural (#1239).
