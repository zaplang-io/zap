- **Iterable `min`/`max` (with `key=`/`default=`) and `sum(xs, start)`** (I#1299,
  decisions/lang/1299-iterable-minmax-sum.md; epic #1286). `min(xs)`/`max(xs)`
  over a list return the lesser/greater element, comparing integers exactly
  (signed `icmp`, never through float), floats via `fcmp`, and strings via
  byte-wise compare; a tie keeps the first element. An empty list raises a
  catchable `ValueError` unless `default=` is given. `key=f` projects each element
  to an orderable key and returns the element with the best key. `sum(xs, start)`
  seeds the accumulator with `start` (positional, like Python), staying exact for
  integers. Generators in the `min`/`max` iterable form, and `str`/`bigint`
  support, remain follow-ups.
