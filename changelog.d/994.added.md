- **`net` — socket options** (I#994, epic #985,
  decisions/stdlib/994-socket-options.md). Named setters/getters for the common
  socket options (Zap exposes no `SO_*`/level constants, so there is no generic
  `setsockopt`), matching the intent of Python's `socket.setsockopt` and Go's
  `SetNoDelay`/`SetKeepAlive`/`SetReadBuffer`/`SetWriteBuffer`. **Setters:**
  `net.set_reuseaddr(sock, on)`, `net.set_reuseport(sock, on)`,
  `net.set_nodelay(sock, on)` (disable Nagle), `net.set_keepalive(sock, on)`,
  `net.set_recv_buffer(sock, nbytes)`, `net.set_send_buffer(sock, nbytes)`.
  **Getters:** `net.get_nodelay(sock)` / `net.get_keepalive(sock)` (bool) and
  `net.get_recv_buffer(sock)` / `net.get_send_buffer(sock)` (int64 — the OS
  value, which may be rounded up or doubled). A setsockopt/getsockopt failure
  (e.g. a TCP-only option on a non-TCP socket, or `SO_REUSEPORT` where
  unsupported) raises. Set address-reuse options on an unbound socket before
  binding. Keepalive-interval tuning and multicast membership are deferred
  follow-ups. This completes epic #985 (net transports & options: UDP #991, DNS
  #992, Unix sockets #993, options #994). `net` remains Experimental.
