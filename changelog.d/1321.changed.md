- **The decision index (`decisions/INDEX.md`) is no longer committed to git**
  (I#1321, decisions/tooling/1321-decisions-index-not-committed.md). It was a
  single generated aggregate every ADR-adding PR had to regenerate and commit — a
  merge-conflict hotspot, the same pathology the frozen `DECISIONS.md` had. The
  per-file ADRs are the source of truth and the index is now a derived view:
  `scripts/gen-decisions-index.sh` renders it on demand (`-o -` for stdout) and
  the docs site renders the same. CI validates the ADR *sources*
  (`--validate`: required frontmatter present) instead of checking a committed
  copy. Contributors no longer regenerate or commit any index. Repo-process only.
