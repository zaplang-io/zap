- **Reflected comparison operators (I#1198, epic I#1189, decisions/lang/1198-reflected-comparison.md).** `==`/`!=` and `< <= > >=` now reflect onto the right operand when the left cannot handle them, completing the reflected set begun in #1180. A right-hand type defines `__req__(self, L) -> bool` (symmetric equality) and/or `__rcmp__(self, L) -> int` (relationals; returns the sign of `left <=> self`, so the four derive exactly as from the forward `__cmp__`). Left `__eq__`/`__cmp__` by name still win; a built-in left works too (`3 < v` → `v.__rcmp__(3) < 0`). Purely additive — only paths that errored before are affected; a missing handler on both sides is still ZAP4071.
