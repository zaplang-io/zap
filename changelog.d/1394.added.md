- **A `@derive` generator can dispatch on a type's kind at its top level**
  (I#1394, epic #1371, decisions/lang/1394-generator-kind-dispatch-pruning.md). A
  generator's top-level `if reflect.type_info(T).kind.name == "enum": … else: …`
  is now comptime-pruned per instantiation, so **one** registered generator
  handles both structs and enums (and the dead-kind branch's kind-specific
  constructs never reach lowering). The comptime evaluator resolves a type
  parameter `T` to the concrete instantiation when evaluating `reflect.type_info(T)`,
  and a comptime-constant `if` in a specialized generic is pruned to its taken
  branch (ordinary, non-generic code is unaffected; a non-comptime condition
  stays a runtime `if`). Also: `reflect.field` now desugars inside assignment
  statements (`acc = acc + reflect.field(…)`) and nested runtime control flow, so
  a fold-style codec works. This unblocks a real codec derived across structs and
  enums, and recursion where an enum payload is a derived struct (I#1375).
