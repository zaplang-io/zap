- **`datetime.add` / `datetime.diff` / comparisons now observe the sub-second
  fraction** (I#1148, decisions/stdlib/1148-subsecond-datetime.md). `add` no
  longer truncates the `Duration` (#1047) to whole seconds: it carries the
  sub-second remainder into the result's fraction, with correct carry/borrow at
  second (and so day/month/year) boundaries — `add(t, time.micros(1))` is now
  distinct from `t`. `diff` returns the exact nanosecond difference, and
  `before` / `after` / `equal` order by `(instant, nanosecond)`. The `Duration`
  type itself is unchanged (D-0227).
