- **`any` / `all` / `reversed` built-ins** (I#1285,
  decisions/lang/1285-any-all-reversed.md; epic #1286). `any(xs)` / `all(xs)`
  reduce a `list[bool]` to a `bool` (`any([])` is `False`, `all([])` is `True`),
  draining the list once and folding with `or` / `and`. `reversed(xs)` returns a
  new `list[T]` with the elements reversed, leaving `xs` unchanged, so it drops
  straight into `for x in reversed(xs)`. Rejections: a non-`list[bool]` argument
  to `any`/`all` or a non-list argument to `reversed` (ZAP4024), wrong arity
  (ZAP4025), and keyword arguments (ZAP4023). `enumerate` and `zip`, `any`/`all`
  over generators and non-bool elements, and `reversed` over `str`/other
  iterables remain follow-ups.
