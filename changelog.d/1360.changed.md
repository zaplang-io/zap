- **Every coroutine `time.sleep` now frees its worker instead of only in-scope
  sleeps** (I#1360, decisions/runtime/1360-coroutine-sleep-fd-less-timer-park.md).
  A `time.sleep` / `sleep_ns` / `sleep_for` on any coroutine — including a
  `spawn detached` coroutine with no owning `scope:` — now parks on a fd-less
  scheduler timer and frees its worker M so sibling coroutines run during the
  wait, generalizing the in-scope cancellable sleep from I#1357. The park
  consumes no file descriptor, so many coroutines can sleep concurrently without
  exhausting them (I#1357 backed each in-scope sleep with a pipe fd; that park is
  replaced). Cancellation, millisecond-class resolution, and the blocking
  nanosecond-exact fallback on a native thread (`main`) or non-Linux build are
  unchanged. The `time.sleep*` surface is unchanged.
