- **E4: the Json and Yaml codec shadows gain an `Optional[T]` decode branch**
  (I#1522, epic #1429, decisions/lang/1522-codec-optional-decode.md). An `Optional`
  scalar field now round-trips through the library `@derivable` decoder, agreeing
  with the built-in both ways, for both `Some` and `None`. Unblocked by #1506
  (`reflect.set_field` desugars inside a `match` arm) and #1517 (built-in Yaml
  `Optional` parity). The decode mirrors the built-in's D-0065 semantics and is
  null-safe: a dict-membership check (`if name in m`) guards the DOM read, so an
  absent key — the built-in omits a `None` optional on encode — maps back to `None`
  instead of dereferencing a missing entry. `list` / `dict` fields stay out of scope
  (the built-in codecs do not support collection fields yet).
