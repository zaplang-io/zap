- **E5: library `@derive(Json)` encode for the AWS `@json` hooks** (I#1555, epic
  #1551, decisions/lang/1555-json-encode-aws-hooks.md). The library `JsonBytes`
  generator now reproduces the AWS field hooks (#346, D-0086) byte-identically to
  the built-in: a `bytes` field encodes as standard-padded base64
  (`base64.encode`), and a `DateTime` field as epoch seconds (default) or ISO-8601
  (`@json(timestamp="iso8601")`) via `datetime.to_timestamp` / one-arg
  `datetime.format`. The timestamp form is read off the field's decorator through
  nested `comptime for` over `f.attrs` — the first derive generator to iterate
  field attributes at comptime. No new comptime primitive; the built-in codegen
  and prelude are untouched.
