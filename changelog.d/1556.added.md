- **E5: library `@derive(Json)` encode for the AWS open string enum** (I#1556,
  epic #1551, decisions/lang/1556-json-encode-enum.md). The library `JsonBytes`
  generator now encodes an `@json(open)` enum byte-identically to the built-in:
  a known payload-free variant → the JSON string of its name, the `Unknown(str)`
  fallback → the JSON string of its carried value, consumed via the reflected-
  variant match form (`case comptime v in reflect.type_info(T).variants as
  payload`, #1374). ENCODE only — open-enum decode is blocked on the enum/generic
  construction gap #1561 (reported under #1248, not worked around). No new
  comptime primitive; the built-in codegen and prelude are untouched.
