- **`argparse` object parser — CPython parity** (I#1713,
  decisions/lang/1713-argparse-python-parity.md). `ArgumentParser` gains option
  aliases (`alias=`), `nargs` (`?`/`*`/`+`/`N`/`...` with `get_list`/
  `get_int_list`/`get_float_list`), `parse_known_args` and
  `parse_intermixed_args`, the full action set (`store_const`, `append`,
  `append_const`, `count`, `extend`, `version`, with `get_count` /
  `version_requested`), short-option grouping and attached values (`-xvf`,
  `-ovalue`, `-o=value`), `dest=` override, the `bool`/`bigint`/`complex`/
  `char`/`bytes` type tags (with `choices` compared against the converted
  value), parser-wide `argument_default`, `set_default`/`get_default`,
  unambiguous long-option abbreviation (`allow_abbrev`), subparser
  `required`/`aliases`/`title`/`description`/`metavar`, help epilog, `{a,b,c}`
  choice metavars, and `%(default)s`/`%(prog)s` interpolation. The remaining
  construction options are chainable setters (`set_epilog`, `set_add_help`,
  `set_allow_abbrev`, `set_prefix_chars`, `inherit`, …). Three scan-found bugs
  are fixed: negative non-integer values now bind (`--temp -1.5`), `required=True`
  on a positional is a declaration error, and group/subparser descriptions
  render instead of being ignored. The parser still raises catchable errors
  rather than exiting, and `-h`/`version` set flags without auto-printing.
  Because `const` is a reserved keyword the `const` action value is spelled
  `const_value`. The legacy flat `argparse.*` API is unchanged.
