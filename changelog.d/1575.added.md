- **comptime: a reflected type argument in an explicit type-argument call**
  (I#1575, epic #1248, decisions/lang/1575-reflected-type-argument.md). A derive
  generator can now name an element type through reflection —
  `gen[f.ty.elem](...)` for a `list` element, `gen[f.ty.value](...)` for a `dict`
  value, `gen[f.ty](...)` for a field. Comptime specialization rewrites the
  reflected type-argument subscript (a comptime type carrying its use-site
  declared type) into an `Expr::TypeArg`, so the enclosing generic call resolves
  against the concrete element type; previously it failed with `unknown variable`
  / `cannot infer type argument`. This unblocks decoding a nested derived struct
  that is a `list` element or `dict` value (E5 `@derive(Json)` library decode,
  #1557) and the same recursion for E6 serde `deserialize`. Enum-variant and
  generic-struct construction remain the separate gap #1561.
