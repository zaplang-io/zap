- **`datetime.zone()` rejects a name with an embedded NUL or an overlong name**
  (I#1172). Named-zone lookup now validates the whole length-delimited Zap
  string before comparing against the bundled IANA table, so
  `datetime.zone("America/New_York\x00suffix")` no longer silently truncates to
  `America/New_York`; it raises the same catchable unknown-zone error as any
  absent name. The fix covers all three name-to-zone paths (`zone`,
  `astimezone`'s resolve, and the zone-id handle).
