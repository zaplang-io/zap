- **`net` — IP presentation ↔ wire conversion** (I#1261,
  decisions/stdlib/1261-ip-presentation-wire.md). Pure, I/O-free conversion
  between IP address text and its network-order octets, the stdlib equivalent of
  Python's `socket.inet_pton` / `inet_ntop` (no sockets, no DNS). **Surface:**
  `net.inet_pton(family, text) -> bytes` parses an IPv4/IPv6 literal into its
  network-order octets (4 bytes for `"ipv4"`, 16 for `"ipv6"`);
  `net.inet_ntop(family, packed) -> str` formats 4-/16-byte octets back into
  canonical text — RFC 5952 for IPv6 (lowercase, longest-run `::`, single zero
  never compressed) with `::ffff:a.b.c.d` IPv4-mapped handling. `family` is
  keyword-bindable. Divergences from Python
  (`docs/PYTHON_DIFFERENCES.md`): `family` is the portable string `"ipv4"` /
  `"ipv6"`, not a platform-specific `AF_*` integer; every rejection (malformed
  text, family/text mismatch, unknown family, wrong packed width) raises one
  catchable `ValueError`; IPv6 output is canonical and byte-identical across
  platforms. `net` remains Experimental.
