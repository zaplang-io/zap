- Type-parameter bounds may now reference other type parameters, including the one being bound: `def scale_all[T: Scaler[f64, T]](…)` / `struct S[E: Scaler[f64, E]]`. The bound's arguments are captured and substituted — at the definition a call through the parameter is typed by the interface's substituted signature (e.g. result `T`), and at each instantiation the parameter is substituted into the bound (`Scaler[f64, Matrix]`) before the conformance check. A generic-interface bound with the wrong number of type arguments is rejected (`ZAP4084`). (I#1206, part of epic I#1204; the mechanism #1199's operator-capability bounds need.)
