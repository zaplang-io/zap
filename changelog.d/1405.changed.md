- **Soft (contextual) keywords: `scope`, `select`, `match`, `case`** (I#1405,
  I#1411, epic #1413, decisions/lang/1405-soft-contextual-keywords.md). These
  four words are demoted from hard reserved keywords to **contextual** keywords:
  each is a keyword only in its own statement/clause slot (the `scope(...):`,
  `select:`, `match EXPR:` statements and their `case` arms) and an ordinary
  identifier everywhere else — usable as a struct field, a parameter, a
  named-argument label, an attribute read, and a general expression. This
  unblocks the OAuth package's `scope` token field / `scope=` keyword argument
  (RFC 6749 §5.1) and matches common identifiers in the Python libraries Zap
  mirrors (`select(...)`, `re.match(...)`). As in CPython's own soft `match`, a
  statement-leading `match` is distinguished from a call/name use (`match(x)`,
  `match = v`, `match.attr`) by a bounded lookahead for the `:`+block marker.
  The change is strictly widening — every program that parsed before still
  parses identically — and the keyword statement forms are unchanged.
