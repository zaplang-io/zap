- **`bytes` — bulk byte-table translation: `bytes.maketrans` + `bytes.translate`**
  (I#1099, decisions/stdlib/1099-bytes-translate-maketrans.md). `bytes.maketrans(frm,
  to)` builds a 256-byte translation table (identity except `frm[i] → to[i]`;
  `frm`/`to` must be equal length or it raises a catchable `ValueError`).
  `b.translate(table)` rewrites the whole buffer in one native pass
  (`out[i] = table[b[i]]`; `table` must be exactly 256 bytes, else a catchable
  `ValueError`); `b.translate(table, delete)` additionally drops any byte whose
  value is in the `delete` set — deletion wins over remapping, matching CPython.
  High bytes `0x80..0xFF` translate correctly (unsigned, no sign extension).
  Arguments are positional-only, as in CPython. This is a `bytes`-only method,
  distinct from `str.translate`'s `dict[str, str]` code-point map (#1034), and
  replaces the per-byte interpreted loop the reverse-complement benchmark
  (zaplang-io/zap-benchmarks#52) needed.
