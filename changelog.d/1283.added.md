- **Scalar `abs` and `divmod` built-ins** (I#1283,
  decisions/lang/1283-scalar-abs-divmod.md; epic #1286). `abs(x)` returns the
  magnitude of a numeric scalar — a signed integer stays an exact `int64` (via an
  integer negate + `select`, **never** through float), an unsigned value is
  returned unchanged (`uint64`), and a float yields its `float64` magnitude via
  libm `fabs` (correct for `-0.0`/`NaN`). `abs(INT64_MIN)` raises a catchable
  **ArithmeticError** instead of wrapping. `divmod(a, b)` returns the
  `(quotient, remainder)` pair as a 2-tuple of the operands' joined type, using
  the same floored `//` and `%` as the operators (so `divmod(a, b) == (a // b,
  a % b)` for every sign), with a zero divisor raising **ZeroDivisionError**.
  Both reject wrong arity (ZAP4025), keyword arguments (ZAP4023), and
  non-numeric/non-scalar operands including `bigint`/`complex` (ZAP4024);
  `divmod` also rejects mixing signed and unsigned (ZAP4015). `bigint`/`complex`
  support is a follow-up.
