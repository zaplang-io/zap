- **A generic function's bound type parameters now flow into its return type**
  (I#1623, decisions/lang/1623-generic-return-binding.md). When a call binds a
  generic function's type parameters from its arguments, the binding substitutes
  into the result type instead of erasing to `Unknown`: with
  `def option[T](Type[T] kind, T default) -> T`, `int64 n = option(int64,
  default=1)` compiles and `str s = option(int64, default=1)` is now rejected (the
  result is `int64`, not `str`). An unbound type parameter stays `Unknown`, so an
  un-inferable generic return remains permissive, and a non-generic call is
  unaffected. Scoped to free functions; binding a generic method's return type is
  a follow-up.
