- **E6.1: serde core over comptime reflection** (I#1562, epic #1552,
  decisions/lang/1562-serde-core.md). A general, format-agnostic (de)serialization
  layer: `Serializer` / `Deserializer` backend interfaces plus the shared generic
  free functions `serialize[T, S: Serializer](value, s)` and
  `deserialize[T, D: Deserializer](d) -> T`. The field walk is a compile-time
  `comptime for` over `reflect.type_info(T).fields` and the backend is an
  interface-bounded type parameter, so dispatch is fully **monomorphized and
  unboxed** (direct `fieldget`/`fieldset` and direct `@Backend__emit_*` calls, no
  vtable) — a codec becomes a pure library with no per-codec compiler change (the
  payoff of epic #1248), explicitly not runtime reflection. Covers scalar
  (`int64`/`str`/`bool`) fields and nested-struct encode. Enum / generic-struct
  *deserialize* is blocked on the `reflect.construct` generalization (#1561) and is
  not attempted; a length-prefixed backend buffers its own count (no static
  field-count primitive). No new core comptime/reflection primitive was added.
