- **`net` — Unix domain sockets (AF_UNIX)** (I#993, epic #985,
  decisions/stdlib/993-unix-domain-sockets.md). Local IPC over a filesystem
  socket path, matching Python's `socket` (`AF_UNIX`) and Go's `net`
  (`"unix"`/`"unixgram"`). **Stream:** `net.listen_unix(path) -> listener` and
  `net.connect_unix(path) -> conn`, which reuse the existing `net.accept` /
  `net.recv` / `net.send` / `net.close_conn` / `net.close_listener` and the read
  deadlines unchanged. **Datagram:** `net.unixgram_socket()` (unbound) +
  `net.unixgram_bind(sock, path)` + `net.sendto_unix(sock, data, path) -> int64`
  + `net.recvfrom_unix(sock, n) -> (data, path)` (the sender's bound path, `""`
  for an unbound sender). Non-blocking on the netpoller like the INET
  transports. **POSIX-only** — the Windows build raises a catchable "not
  supported" error. Notes: only filesystem pathnames (Linux abstract names are
  rejected); `listen_unix` does not unlink a stale path (remove it first, as in
  Python/Go); peer-credential access is a deferred follow-up. `net` remains
  Experimental.
