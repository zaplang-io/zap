- **`@derive(Yaml)` no longer miscompiles an `Optional[T]` field, and now
  encodes one** (I#1514, decisions/lang/1514-yaml-optional-field.md). The Yaml
  encoder recursed into a monomorphized `Optional$T` aggregate as if it were a
  nested `@derive(Yaml)` struct, emitting a call to a non-existent
  `Optional$T__to_yaml` — an unresolved external symbol that escaped the host
  build and only failed deep in the LLVM-18 / aarch64 matrix. `to_yaml` now
  handles a top-level `Optional[T]` field directly (parity with `@derive(Json)`,
  D-0065): `name: <inner>` when `Some` (scalar inline or nested struct as an
  indented block), `name: null` when `None`; `from_yaml` already decodes an
  absent key or explicit `null` back to `None` through the shared JSON decode
  core, so the field round-trips. A nested `Optional` payload
  (`Optional[Optional[...]]`) is now a clean "unsupported yet" compile error
  instead of a dangling symbol.
