- **Reflected binary operators — sema recognition (I#1186, epic I#1189, RFC in Discussion #1182).** The type-checker now recognizes the reflected operator dunders (`__radd__ __rsub__ __rmul__ __rtruediv__ __rfloordiv__ __rmod__ __rpow__ __rand__ __ror__ __rxor__ __rlshift__ __rrshift__ __rmatmul__`, D-0047) and resolves `a OP b` against the **right** operand's reflected dunder as a fallback when the left operand cannot handle the operator itself — so a user type (e.g. a package `RelativeDelta`) can participate in arithmetic with a core left operand (`dt + rd`). The left/built-in path always wins; reflected is consulted only where the expression errored before, so this is purely additive. A left type that defines the forward dunder by name commits the operator to the left (a mismatched RHS is an ordinary error, not a reflected reroute). Execution lowering is tracked separately in I#1187.
