- **Returning decorators compose when any layer can be innermost, via a uniform
  generic seam** (I#1647, decisions/lang/1647-uniform-generic-seam.md). A
  decorator's handler parameter may now be typed as the receiver method's **own
  generic type parameter** (`def command[Inner](self, Inner previous) -> Command`),
  not only the literal `fn([C,] Namespace)` seam. The innermost use adapts the
  decorated handler into that parameter (scalars bind from the `Namespace`,
  `Depends(...)` parameters inject, the context is inferred from the handler's
  first non-scalar parameter); an outer use threads the previous layer's return
  value into it. Because the parameter is generic, one signature serves every
  stack position, so a repeated decorator (e.g. stacked `@cli.argument(...)`) no
  longer needs incompatible signatures — closing the `ZAP4021` mismatch a non-last
  layer hit before. The literal seam, bottom-up order, explicit context (#1621),
  optional/positional metadata (#1626/#1645) and `Depends` injection (#1646) are
  unchanged, and no library-specific built-in is required.
