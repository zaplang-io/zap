- **Soft (contextual) keywords, Tier 2: `spawn`, `when`, `do`, `unsafe`,
  `python`** (I#1412, epic #1413, decisions/lang/1412-soft-contextual-keywords-tier2.md).
  These five words are demoted from hard reserved keywords to **contextual**
  keywords, completing the epic after the Tier-1 set (`scope`/`select`/`match`/
  `case`, #1405/#1411). Each is a keyword only in its own slot — the `do:`…`while`
  and `unsafe:` statements, the `when target.*:` conditional-compilation
  statement/item, the `spawn <call>` statement, and the `import python "mod"`
  interop head — and an ordinary identifier everywhere else (struct field,
  parameter, named-argument label, attribute read, general expression). `spawn`
  and `python` have no `:` marker, so they resolve toward the keyword at the
  statement head / interop head and toward an identifier elsewhere; a consequence
  is that `import python` (no string) now imports a logical module named
  `python`. The change is strictly widening — every program that parsed before
  still parses identically — and all existing statement/import forms are
  unchanged.
