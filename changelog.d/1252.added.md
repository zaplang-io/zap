- **Typed `reflect.field(value, comptime i)` access (E2)** (I#1252, epic #1249,
  decisions/lang/1252-reflect-field.md). The comptime field index resolves to
  the field at that declaration position and desugars to the ordinary typed
  field access `value.<name>` — a direct, unboxed field load of the field's
  statically-known type, never an `any`. Because it desugars to ordinary field
  access, the existing per-layout lowering compiles it unchanged for all three
  struct layouts (value-struct, heap-struct, `@scoped`), with no new codegen. An
  out-of-range comptime index is a compile error at the comptime site, never a
  runtime out-of-bounds. Read access only in v1 (field write deferred). Wired to
  mono (`reflect_field_access`, `unroll_struct_fields_with_access` — the combined
  `comptime for` + `reflect.field` pipeline). Compiler-internal and host-tested;
  **no `reflect` keyword surface yet** (the parser surface + statement-position
  wiring, and nested access across container element types #1253, are
  follow-ups); no behavior change for existing programs.
