- **`argparse` object parser — read-only completion context** (I#1712,
  decisions/lang/1712-argparse-completion-context.md).
  `ArgumentParser.completion_context(words, prefix) -> CompletionContext` reports
  what the cursor word completes in a partial command line, reusing the core
  token matching (subcommand selection, value options vs flags,
  `--option=value`, `--`). It returns the selected subcommand path, whether
  options are still allowed, the active value-taking option (with the value
  prefix split out) or next positional destination, candidate completions, and
  whether a completed word was invalid. The cursor word is treated as incomplete
  — a partial value is never validated as a full choice and the selected
  parser's required arguments are never enforced — and the query never parses,
  prints, exits, or changes `parse_args`. Unblocks shell-completion generation
  in the CLI package.
