- **A returning decorator's omitted `name` defaults to the decorated
  declaration's name** (I#1665, decisions/lang/1665-decl-name-default.md). When the
  outermost returning decorator's receiver declares a `str name` parameter that the
  call does not bind, the desugar fills it with the declaration's name (Click-style
  `@command` naming), so a package can recover it — `@cli.command` over
  `def greet(...)` desugars to `cli.command(handler=greet$adapter, name="greet")`,
  and `greet.name == "greet"`. An explicit `name=` always wins, an inner
  `@option`/`@argument` is never auto-filled, and a receiver with no `str name`
  parameter is unchanged. Resolves the decl-name sub-ask split from #1647.
