- **`int(s, base)`, `bytes(int)`, and `print()` formatting keyword arguments** (PR#1458, decisions/lang/1458-int-base-bytes-int-print-kwargs.md). `int(str, base)` parses in base 2..=36, or base 0 to auto-detect a `0x`/`0o`/`0b` prefix (invalid digit/base → catchable `ValueError`). `bytes(n)` returns `n` zero bytes (negative → `ValueError`). `print(*values, sep=" ", end="\n", file=stdout_fd, flush=False)` gains the formatting keyword options — `file=` is an `int64` fd (default stdout), `flush=` a no-op on the raw-fd path. First batch of the overload-parity epic #1386 (`sum`/`complex`/`set` were already done).
