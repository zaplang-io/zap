- **Built-in `@derive(Json)` supports `list[T]` fields** (I#1530, epic #1529,
  decisions/lang/1530-json-list-field.md). A `list` field now encodes as a JSON
  array and decodes a JSON array back into a list, for element types `int` /
  `float` / `str` / `bytes` / nested `@derive(Json)` struct. Encode string-builds
  the array recursing into the per-element encoder; decode reads the DOM array via
  a new `__json_as_array` prelude accessor and decodes each element. Unsupported
  element kinds (`bool`/`char`/`enum`, and nested-collection elements like
  `list[list[...]]`), and `dict`/`set` fields, remain a clean "unsupported yet"
  error (follow-ups: dict #1531, Yaml parity #1532, nested-collection elements
  #1533).
