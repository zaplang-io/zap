- **Generic enum construction with explicit type arguments**
  (I#1402, epic #1371, decisions/lang/1402-generic-enum-explicit-type-args.md). A
  generic enum can now be built with an explicit type argument and a variant
  path — `Box[int64].Full(9)`, the payload-free `Box[int64].Empty`, and
  multi-field variants — where previously the form failed with
  `error[ZAP3001]: unknown name 'Box'` because the `Box[int64]` subscript was
  type-checked as a value. This is the only way to name an instance when no
  variant payload mentions the type parameter, so it unblocks generic-enum
  `@derive` end-to-end: a derived method now runs on an explicitly-constructed
  generic enum value. The variant name and payload arity are checked exactly as
  the non-generic `Enum.Variant` forms are, and the form is gated to genuinely
  generic enums.
