- **serde breadth: `enum` types** (I#1606, epic #1552,
  decisions/lang/1606-serde-enum.md). The bundled `serde` foundation (#1570) now
  (de)serializes `enum` types. `serde.Serializer` gains `emit_variant` and
  `serde.Deserializer` gains `read_variant`; the generic `serialize` /
  `deserialize` drivers dispatch on `reflect.type_info(T).kind.name` (`enum` vs
  struct, pruned per specialization). Encode covers all variants (tag + payload);
  decode covers payload-free (constant) variants via `reflect.construct_variant`.
  A payload-carrying variant is a clear compile error on decode this slice.
  Downstream codecs (e.g. `zaplang-io/msgpack`) need a matching backend update
  (`emit_variant` / `read_variant`).
