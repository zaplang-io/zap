- **`dict` / `set` — optional initial-capacity hint on construction + `reserve()`**
  (I#1083, decisions/stdlib/1083-dict-set-capacity.md). `dict[K,V](capacity=n)`
  and `set[T](capacity=n)` pre-size the open-addressing SoA table once so a
  known-large build skips the ~18 regrow + full-rehash cycles it would otherwise
  pay growing from empty; `d.reserve(n)` / `s.reserve(n)` do the same after
  construction (growing a live table without losing entries, a no-op when already
  big enough, never shrinking). `capacity` is a lower-bound hint rounded up to the
  table's power-of-two / 0.75-load policy; `0` or omitted is the default, a
  negative literal is a compile error, and a hint smaller than the eventual size
  still grows as before. This is a Zap extension beyond the Python surface
  (CPython `dict`/`set` have no capacity constructor), modelled on Java
  `HashMap(n)` / Rust `with_capacity` / Go `make(map, n)`; `reserve`'s argument is
  positional, `capacity` is keyword-only. Iteration order remains unspecified.
