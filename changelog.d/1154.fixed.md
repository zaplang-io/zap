- **A comprehension can now iterate a `dict` directly** (I#1154). `[k for k in
  d]`, `{k for k in d}`, a generator `(k for k in d)`, and a dict comprehension
  whose source clause is a dict all iterate the dict's keys — Python semantics
  (#299), matching the statement `for k in d` loop — instead of failing IR
  lowering with `error[ZAP6001]: value of type Dict(...) is not iterable
  (D-0048)`. Sema already permitted it; only the comprehension lowering path
  lacked a `dict` arm in its iteration protocol. Iteration order stays
  unspecified (#1066). The `dict`-key `set(...)`/`oset(...)` constructors
  benefit from the same arm.
