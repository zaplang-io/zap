- **`reflect.construct` zero-inits an enum-typed field** (I#1603, epic #1248,
  decisions/lang/1608-reflect-construct-enum-container.md). `reflect.construct(T)`
  now zero-initializes an enum field to the enum's first variant (a throwaway base
  a decoder overwrites), so a struct with an enum field — e.g. a `@derive(Json)`
  struct holding an `@json(open)` enum — can be zero-constructed and decoded.
