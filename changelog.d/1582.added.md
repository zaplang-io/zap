- **`RegexError` — a dedicated regex exception type** (#1582,
  decisions/lang/1582-regex-error.md). A regex failure (an invalid pattern that
  PCRE2 cannot compile, or a bad replacement-group reference in a `s///`
  substitution) now raises a dedicated **`RegexError`** instead of the
  provisional bare `ValueError` that #1566 introduced. `RegexError` subclasses
  `ValueError` (`RegexError` ⊂ `ValueError` ⊂ `Exception`), so `except
  RegexError` selects just the regex case while existing `except ValueError` and
  `except Exception` handlers keep catching it unchanged — no migration. The
  message still carries the PCRE2 diagnostic, and an uncaught regex failure still
  reports it and exits 1. `raise RegexError("…")` and `except RegexError` are
  now available to user code.
