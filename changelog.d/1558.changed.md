- **`@derive(Json)` is now a library codec, not a compiler built-in** (I#1558,
  epic #1551, decisions/lang/1558-retire-builtin-json.md). `@derive(Json)` is
  sugar for two prelude `@derivable` codec traits (`to_json` / `from_json`), plain
  Zap over the `JsonValue` DOM + `reflect.*`, injected only when a module derives
  Json (so other programs are byte-for-byte unchanged). It reproduces the retired
  built-in byte-for-byte — field-order objects, `Optional` omit-on-`None`,
  `bytes`→base64, `DateTime`→epoch/ISO-8601 per `@json(timestamp=)`, the
  `@json(open)` string enum, and nested collections — and deletes the JSON-only
  built-in codegen (`gen_json_to_method` / `gen_json_from_method` / the open-enum
  path) and the `to_json` sema synthesis / `Json` `DERIVABLE_TRAITS` entry. The
  built-in `@derive(Yaml)` codec (which shares the JSON field encoder and decode
  core) is unaffected. Every existing Json golden stays byte-identical.
