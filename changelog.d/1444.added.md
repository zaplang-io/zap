- **E4 dogfood: `@derive(Hash)` shadow-proved over the `@derivable` mechanism**
  (I#1444, epic #1429, decisions/lang/1444-derive-hash-shadow-prove.md). A library
  `@derivable` generator reproduces the built-in hash fold byte-identically —
  seed 0, `hash_combine` over each field's `.__hash__()` in declaration order — so
  a struct's built-in `__hash__()` and the library shadow return the same value, as
  a behavior-identical golden asserts. Shadow proof only — the built-in `Hash`
  (and the implicit value-struct auto-derive of Eq+Hash) are left untouched.
