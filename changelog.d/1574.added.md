- **serde breadth: `float64` and `bytes` fields** (I#1574, epic #1552,
  decisions/lang/1574-serde-breadth-floats-bytes.md). The bundled `serde`
  foundation (#1570) now (de)serializes `float64` and `bytes` struct fields in
  addition to `int64` / `str` / `bool` + nested structs: `serde.Serializer` gains
  `emit_float` / `emit_bytes`, `serde.Deserializer` gains `read_float` /
  `read_bytes`, and the generic `serialize` / `deserialize` drivers gain the
  matching kind branches. Note: because `serde` is bundled, widening the backend
  interfaces requires every `Serializer` / `Deserializer` implementor to add the
  new methods — in-repo backends are updated here; downstream codecs (e.g.
  `zaplang-io/msgpack`) need a matching backend update.
