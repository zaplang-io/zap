- **Enum `@derive` generators can discriminate variants at runtime**
  (I#1374, epic #1371, decisions/lang/1374-comptime-match-arm-lowering.md). A
  `@derivable` generator can now match an enum value with a **comptime-generated
  match arm**, `case comptime <v> in reflect.type_info(T).variants [as payload]:`,
  inside an ordinary `match value:`. Monomorphization expands it into one variant
  pattern arm per variant — binding the payload fields, with `reflect.field(
  payload, i)` reading the i-th field and `comptime <v>.name` / `comptime for f
  in <v>.fields:` resolving per variant — and lowers it through the existing
  enum-match machinery (tag discrimination + payload loads), so it is one
  exhaustive match, not a chain of tag tests. Tier-1 constant and tier-3 payload
  enums are both supported. This completes the runtime half of enum deriving
  begun in I#1373 (the forwarding synthesis); a real codec over an enum and
  nested/recursive breadth land in I#1375.
