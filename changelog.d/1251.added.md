- **`comptime for` loop unroller wired to monomorphization (E2)** (I#1251, epic
  #1249, decisions/lang/1251-comptime-for-unroller.md). The compile-time-unrolled
  loop over a type's reflected `fields`/`variants`: the body is cloned and
  specialized once per field — comptime operands (`f.index`, `f.name`, a comptime
  `rename_all` call) fold to literals, runtime operands are preserved — never a
  runtime loop over `any`, no boxing. Each iteration stays an ordinary
  outlineable **call**, never a forced inline (HQ3), so code size is bounded by
  field count. The unroll engine lives in `zapc_comptime` (building on the #1250
  evaluator) with a no-sema reflector that builds the E1 `TypeInfo` records
  straight off the concrete AST; mono reflects the post-substitution declaration
  and runs it. Compiler-internal and host-tested; there is **no `comptime`
  keyword surface yet** (the parser surface + typed `reflect.field` (#1252) +
  container recursion (#1253) are follow-ups) and no behavior change for existing
  programs.
