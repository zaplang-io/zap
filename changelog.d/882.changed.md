- **`arena` cap-overflow / heap-OOM now raises `MemoryError`** (I#882,
  decisions/lang/882-memoryerror-exception.md; arena epic #553, D-0158).
  Replaces the arena v1 stopgap, which raised a `RuntimeError` whose message
  merely named it a memory error. `except MemoryError` and `except Exception`
  catch it; `except RuntimeError` no longer does. Breaking for the experimental
  v1 arena surface only — the `RuntimeError` was always a documented stopgap and
  the design (`docs/design/arena.md` §2.3/§3) always specified `MemoryError`.
