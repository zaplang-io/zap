- **`comptime` keyword — the compile-time surface parser (S1)** (I#1297, epic
  #1296 / #1248, decisions/lang/1297-comptime-surface-parser.md). The language
  gains the `comptime` keyword (locked decision 4 of epic #1249), with two
  forms: `comptime for <target> in <expr>:` (a compile-time-unrolled loop, a
  distinct AST node from the runtime `for`) and `comptime <expr>` (a prefix that
  forces compile-time evaluation, covering a comptime operand such as
  `reflect.field(v, comptime f.index)` and a comptime binding via
  `auto x = comptime …`). The existing `comptime.<builtin>` qualified call
  (`comptime.error(...)`, #1256) keeps working — the token after `comptime`
  disambiguates. This slice is the **parser surface only**: the syntax parses,
  round-trips through `render`/`zap fmt`, and is documented in GRAMMAR.ebnf, but
  comptime evaluation/unrolling is not wired yet (sema reports it as not-yet-
  implemented, wired in #1298). **Breaking (pre-1.0):** `comptime` is now a
  reserved word and can no longer be used as an identifier.
