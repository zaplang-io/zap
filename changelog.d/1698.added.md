- **`argparse` object model — typed setters that replace a resolved `Namespace`
  binding in place** (I#1698, decisions/lang/1698-namespace-set.md). The parsed
  `Namespace` now exposes `set_str`, `set_int`, `set_float` and `set_flag`
  alongside its typed getters, so a parameter validation/transform callback
  (zaplang-io/cli#14, via the #1544 handler adapter) can write its typed result
  back into the parse result. A setter replaces an **already-declared**
  destination's value only — argv presence (`has`) and help state are left
  untouched (a replacement does not re-mark a default as "supplied"), sibling
  bindings and any separate parse are unaffected, and a binding that reached the
  namespace through a parent parser selecting a subcommand is replaced the same
  way. Replacing an unknown destination raises a catchable `KeyError` (the
  documented typed error path). `set_str` is also the universal form — since
  every getter reads the same stored string it is how a
  `char`/`bytes`/`bigint`/`complex` binding is replaced (`set` alone is a
  reserved type name).
