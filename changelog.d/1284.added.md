- **Variadic `min`/`max` and element-typed `sum`** (I#1284,
  decisions/lang/1284-variadic-minmax-sum.md; epic #1286). `min(a, b, c, …)` and
  `max(a, b, c, …)` now take two or more numeric scalar arguments, folding a
  compare + `select` left to right so integer operands stay exact (never routed
  through float) and ties resolve to the first argument. `sum(iterable)` is now
  typed as the iterable's element type instead of loosely, so `sum(list[int64])`
  is an exact `int64` that binds into an int slot (a float-element iterable is
  `float64`; arrays and loosely-typed iterables are unchanged) — a small
  tightening: code relying on `sum`'s former untyped result to fill a
  narrower-than-element slot now sees a type error. The iterable `min(xs)`/
  `max(xs)` form, `key=`, `default=`, and `sum(iterable, start=…)` remain
  follow-ups.
