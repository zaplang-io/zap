- **A struct field default that is a generic constructor now compiles** (I#1152).
  A per-instance field default (D-0038) whose initializer constructed a generic
  type — e.g. `Atomic[int64] state = Atomic(0)` — failed codegen with `call to
  unknown function 'Atomic'`, because monomorphization rewrote only the field's
  *type* and left the default initializer's bare generic constructor
  un-specialized. Field defaults are now monomorphized exactly like a `let`
  initializer or a parameter default, so a generic constructor in a default is
  specialized to its mangled instance (`Atomic$int64(0)`). This applies to
  every generic constructor (built-in `Atomic`/`Mutex`/… cells and user generic
  structs alike), to the `= expr` and `@default(expr)` default forms, and when
  the struct is constructed both in its declaring module and in an importing
  one. Unblocks the per-client atomic socket state in `memcached.Client`
  (zaplang-io/memcached#2).
