- **A variadic `TYPE... args` struct method now collects its trailing arguments
  into one list at the call site** (I#1218, D-0038). A method declared
  `def count(self, bytes... args)` lowers to a callee taking the receiver plus a
  single collected `list`, but the method call site used to forward the receiver
  alone (`c.count()`) or the receiver plus each vararg separately
  (`c.count(b"a", b"b")`) — an argument-count mismatch that type-checked yet made
  native/LLVM compilation fail with `invalid LLVM module: Incorrect number of
  arguments passed to called function!`. Every variadic method call now
  materializes exactly one `list` argument — an empty list for a bare call, one
  list of N for N arguments — matching the free-function variadic path and the
  "received as a `list`" rule (SPEC §7). The fix covers the call site both in the
  declaring module and when the struct is imported from another module or an
  installed package. (The `*`-spread form on a method, `c.count(*args)`, remains
  rejected by sema as a separate pre-#597 limitation.)
