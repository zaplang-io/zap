- **D-0047 operator dispatch now documents reflected binary operators (I#1188, epic I#1189, decisions/lang/1180-reflected-operators.md).** `design/0006-types-and-generics.md` §2.5 is updated: binary-operator dispatch prefers the left operand (built-in rules or a left struct's forward dunder, by name) and falls back to the right operand's reflected dunder (`__radd__` … `__rmatmul__`) when the left cannot handle the operator — else `ZAP4071`. Conformance is implicit/structural; a left type that defines the forward dunder commits the operator (a mismatched RHS is a type error, not a reflected reroute). The change is additive — only paths that errored before are affected. The sema and lowering implementation landed in #1192 and #1194.
