- **comptime/reflect surface compiles end-to-end — sema acceptance (S2b)**
  (I#1298, epic #1296 / #1248,
  decisions/lang/1298-comptime-surface-sema-acceptance.md). Sema now accepts and
  types the comptime fragment, so a program using `comptime for` /
  `reflect.*` compiles and runs end-to-end (completing the mono engine-wiring
  landed earlier for #1298). `reflect.type_info(T)` / `reflect.field(...)` /
  `reflect.has_override(...)` are recognized as comptime builtins (typed
  `Unknown`, their arguments not inferred — `type_info`'s argument is a type, not
  a value); a `comptime for` binds its loop variable and checks its body; and
  `comptime <expr>` has its inner expression's type. The front end no longer
  rejects the fragment (the S1 `ZAP0002` deferral is gone). A `comptime for` over
  a concrete `reflect.type_info(T).fields`/`.variants` now passes parse → sema →
  lowering (mono unrolls it to unboxed field accesses), proven end-to-end by a
  new LLVM golden. A generic `reflect.type_info(T)` with `T` a type parameter is
  still deferred. No behavior change for programs that use no `comptime`.
