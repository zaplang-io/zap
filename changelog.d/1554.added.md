- **E5: byte-identical library `@derive(Json)` encode** (I#1554, epic #1551,
  decisions/lang/1554-json-encode-library.md). A pure library `@derivable`
  generator (`JsonBytes` / `to_jsonbytes`) encodes a struct to JSON **byte-for-
  byte identically** to the built-in `@derive(Json)` encoder, for the scalar /
  `str` / `bool` / `float64` / nested-derived-struct / `Optional[int64]` surface.
  It builds the object envelope by hand in field-declaration order (a `list[str]`
  of `"name":<leaf>` fragments, `",".join`ed and brace-wrapped, a `None`
  `Optional` omitting its key per D-0065), reusing `json.dumps` of a single
  `JsonValue` for each leaf — upgrading the E4 shadow (#1470) from round-trip to
  byte-identical with no new core primitive. The built-in codegen,
  `DERIVABLE_TRAITS` and the prelude are untouched; retiring the built-in is a
  later E5 slice (#1558).
