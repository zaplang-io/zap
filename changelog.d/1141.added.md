- **`net` — TCP keepalive interval tuning** (I#1141,
  decisions/stdlib/1141-keepalive-interval.md, follow-up to #994). The timing
  knobs that make `SO_KEEPALIVE` actionable, in #994's named-option style:
  `net.set_keepalive_idle(sock, seconds)` (idle before the first probe),
  `net.set_keepalive_interval(sock, seconds)` (between probes),
  `net.set_keepalive_count(sock, count)` (failed probes before drop), plus the
  `net.get_keepalive_idle/interval/count(sock) -> int64` twins. Call
  `net.set_keepalive(sock, True)` first. A non-positive value raises
  `ValueError`. POSIX subset (`TCP_KEEPIDLE`/`TCP_KEEPALIVE`, `TCP_KEEPINTVL`,
  `TCP_KEEPCNT`); a knob the platform lacks — all three on Windows — raises a
  catchable "not supported" error (the Windows `SIO_KEEPALIVE_VALS` ioctl path is
  a follow-up). `net` remains Experimental.
