- **`zap test` infers an explicitly-converted generic argument, like `zap run`
  does** (I#1308, decisions/lang/1308-test-harness-threads-sema-types.md). A
  `@test` body building `Optional.Some(int64(0))` — an explicit integer
  conversion, standalone or through a `value=` keyword argument — failed native
  test lowering with `error[ZAP6001]: cannot infer type argument 'T' of generic
  'Optional'`, even though the identical program compiled under `zap run`. The
  native harness lowered its transformed module with an empty type map; it now
  threads sema's inferred `TypeMap`, so the monomorphizer pins the argument
  exactly as it does on the ordinary build path. Test discovery, reporting, and
  the synthesized harness are unchanged.
