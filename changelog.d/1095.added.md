- **`list` — the remaining Python `list` methods: `pop` / `index` / `reverse` /
  `copy`** (I#1095, decisions/stdlib/1095-list-pop-and-methods.md). `xs.pop()`
  removes and returns the last element (O(1), the explicit-stack form the native
  Havlak port needs); `xs.pop(i)` removes and returns the element at `i`
  (negative indices count from the end, remaining order preserved); an empty list
  or an out-of-range index raises a catchable `IndexError`. `xs.index(value[,
  start[, stop]])` returns the first matching position (`ValueError` when absent,
  as in CPython — not `IndexError`), with optional slice-style `start`/`stop`.
  `xs.reverse()` reverses in place; `xs.copy()` is a shallow copy (independent
  membership, shared referents). All preserve element types (int/float/bytes/str/
  reference). Arguments are positional-only, matching CPython. The built-in `list`
  method set is now `append`/`sort`/`extend`/`insert`/`remove`/`pop`/`index`/
  `count`/`reverse`/`copy`/`clear`.
