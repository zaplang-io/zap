- **Comptime purity enforcement — leaf-table reject-lint + interpreter backstop
  + cap (E2)** (I#1254, epic #1249, decisions/lang/1254-comptime-purity-lint.md).
  A single closed **leaf table** (`LeafKind`: I/O, FFI, spawn, channel, time,
  RNG, global mutation, and `Nondet` = dict/set iteration #1066; allocation is
  deliberately NOT tagged) is now shared by two enforcement layers. (a) A static
  reject-lint (`lint_comptime_callable`) rejects a comptime-callable function at
  its definition site if it so much as *mentions* an impure leaf — a join over
  every branch (a provably-dead branch still rejects), with best-effort
  transitive propagation across call levels; an unknown/dynamic callee is
  deferred, never rejected. (b) The bounded interpreter (#1250) consults the same
  table, so an impure call is refused with its leaf kind and the two layers can
  never disagree about membership — and it remains the sole soundness authority
  for everything the lint defers. The fixed step/recursion-depth cap gives a
  clear diagnostic (not a tunable quota). Compiler-internal and host-tested; the
  lint's definition-site wiring lands with the `comptime`/`reflect` surface
  follow-up; no behavior change for existing programs.
