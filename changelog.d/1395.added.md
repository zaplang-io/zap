- **`time.after(d)` — a one-shot timer channel for `select`** (I#1395,
  decisions/runtime/1395-one-shot-timer-channel-after.md). `time.after(d: Duration)`
  returns a buffered `channel[int64]` that receives one value — the monotonic-ns
  instant it fired — after the duration `d`, then blocks (Go `time.After` shape),
  for the `select` timeout idiom:

  ```python
  import time

  select:
      case v = <-work:
          handle(v)
      case fired = <-time.after(time.seconds(5)):
          raise TimeoutError()
  ```

  The timer reuses the fd-less scheduler timer from I#1360, so it frees its
  worker M while waiting and consumes no file descriptor — many concurrent
  timers cannot exhaust them. Its firing coroutine is detached, so a timer that
  is never received neither leaks nor delays program exit. Linux (epoll) only in
  this version; a non-epoll platform keeps a blocking fallback.
