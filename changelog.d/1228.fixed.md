- **Callable module-level constants now dispatch to `__call__`** (I#1228,
  decisions/lang/1228-callable-module-const.md). Calling a module `const` (or any
  module global) whose type defines `__call__` — `MO(-1)`, or `mod.MO(-1)` for an
  imported constant — now lowers to `MO.__call__(-1)`, matching the local-value
  form and Python/dateutil-style callable weekday constants. Omitted default
  arguments (the `MO()` form) and keyword arguments are filled, since the sugar
  now routes through the same path the explicit `MO.__call__(...)` call uses.
  Previously this reported `ZAP6001 "call to unknown function 'MO'"`. The
  plain-value use (`MO.day`) is unchanged.
