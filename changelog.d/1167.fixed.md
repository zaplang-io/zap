- **Generic type-argument inference now reads sema's inferred types** (I#1167,
  epic I#1169). Monomorphization re-derived each generic constructor / call
  argument's type with its own partial inferer, so forms it could not type —
  a module-qualified constant like `math.inf` (I#1162), and the return of a
  built-in call like `len(xs)`, `s.upper()`, or `xs.pop()` (I#1132) — failed
  with `ZAP6001` ("cannot infer type argument 'T'"), even though the type
  checker types them fine. The driver now hands those inferred types to
  monomorphization, which uses them to pin a type argument whenever its own
  inferer comes up empty. An argument it already types is unchanged, so this
  only widens what infers; `Optional.Some(math.inf)`, `Optional.Some(len(xs))`,
  and friends now compile without an explicit `Optional[...]` annotation.
