- **A generic enum method's bound type parameters now flow into its return type**
  (I#1663, decisions/lang/1663-enum-method-return-binding.md). #1642 brought
  argument type-checking to enum instance methods but left the return erased, so a
  mismatched binding target was accepted while the identical struct form was
  rejected after #1643. The enum call path now substitutes the binding into the
  result type the same way: with `enum Color: def make[T](self, Type[T] kind, T
  default) -> T`, `int64 n = c.make(int64, 1)` compiles and `str s = c.make(int64,
  1)` is now rejected (the result is `int64`). The substituted type is used only
  when the method is generic and the binding produced a concrete type, so a
  non-generic enum method result is unchanged; numeric widening still compiles.
  Generic argument consistency and return binding are now symmetric across free
  functions, struct methods, and enum methods.
