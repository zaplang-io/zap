- **Built-in `@derive(Yaml)` supports `list[T]` / `dict[str, V]` fields** (I#1532,
  epic #1529, decisions/lang/1532-yaml-collection-fields.md). A collection field
  now encodes in compact JSON flow (`nums: [1,2,3]`, `scores: {"x":9}`) — valid
  YAML (YAML 1.2 ⊃ JSON) — and decodes through the shared `from_json_value` core
  that `@derive(Json)` uses (which gained list/dict in #1530/#1531), for scalar /
  str / bytes element and value types. A nested-struct element/value in a yaml
  collection is a clean "unsupported yet" error for now (its flow encode would need
  the element's `to_json`, which `@derive(Yaml)` does not emit) — a documented
  follow-up, as are nested-collection elements (#1533).
