# Enum `@derive` comptime surface (#1372, epic #1371)

**Status:** Accepted — the design decision for enum/variant `@derive` (epic
#1371, under E3 #1289). Decided from RFC Discussion #1376 (Option C). This ADR
fixes the surface; the synthesis slice #1373 and the engine/codegen slice #1374
implement it.

## Problem

A derive generator for an enum must, at runtime, decide *which* variant a value
is and read *that* variant's payload. The comptime engine already iterates
`comptime for v in reflect.type_info(T).variants:` over an enum during
specialization (`unroll_enum_variants`), with variant reflect records
(`.name`/`.index`/`.fields`/`.span`), but there is **no runtime
variant-discrimination surface**: `reflect.field` is struct-only, and the
per-variant blocks the loop unrolls cannot test the live variant or bind its
payload.

## Decision

The surface is **`reflect.match`** with arms generated by the `comptime for` over
the type's variants (RFC Option C). The low-level **`reflect.is(value, comptime
variant)`** runtime-tag predicate is kept as the primitive (and the plausible
desugaring target of a `reflect.match`).

```zap
@derivable(Serialize)
def _derive_serialize[T](T value, S s):
    reflect.match value:
        comptime for v in reflect.type_info(T).variants:
            case comptime v as payload:
                s.emit_str(comptime v.name)
                comptime for f in v.fields:
                    serialize_any(reflect.field(payload, comptime f.index), s)
```

Rationale (vs. the rejected alternatives in #1376): a plain `comptime for`
silently becoming a runtime match (Option A) hides the comptime/runtime boundary
and was rejected on the risk posture; an explicit `when reflect.is(...)` chain
(Option B) is a legible primitive but lowers to O(n) tag tests with no single
exhaustive dispatch. `reflect.match` is explicit (names the runtime dispatch),
lowers to one exhaustive match / jump table, is total by construction (arms = all
variants), and reuses the ordinary struct-style `reflect.field` over a per-arm
payload binding — so the only genuinely new construct is `reflect.match` + the
payload bind, not a second `reflect.field` form.

## Resolved sub-questions (concretization)

1. **Payload binding** — `case comptime v as payload:` binds the active variant's
   payload; its fields read with the ordinary `reflect.field(payload, comptime
   f.index)`. A unit / tier-1 variant omits `as` and binds nothing.
2. **Exhaustiveness** — total by construction (arms cover every variant, from the
   comptime iteration); no `default`/`else` in a derive context, so adding a
   variant forces a recompile that re-covers it. The engine asserts coverage.
3. **Kind-switch composition** — inside an arm, a payload field that is a user
   type recurses via the `T: X` bound exactly as a struct field; no special
   casing (#1253).
4. **Scope** — `reflect.match` is a general comptime-reflection construct
   (authoring-tier), introduced for derive but not restricted to it.
5. **Tier-1 constant enums** — `reflect.match` over a no-payload enum lowers to a
   plain tag switch with no payload-load path; unit arms bind nothing.

## Consequence

The synthesis slice (#1373) wires `@derive(X)` on an enum to a forwarding stub
exactly as for a struct (this ADR ships with it); the engine/codegen slice
(#1374) implements `reflect.match` + `reflect.is` + the per-layout payload access.
HQ7 hygiene (gensym'd `payload`, access by index), HQ3 (per-arm/per-field work
stays outlineable), and the kind-switch recursion are inherited unchanged.
